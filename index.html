📲 Instalar como Aplicativo

Para instalar como aplicativo (sem barra de navegador):
  1. Abra este link em HTTPS direto no Google Chrome (não no navegador interno de outro app).
  2. Se já houver um atalho antigo desse endereço na tela inicial, apague-o primeiro.
  3. Toque no menu ⋮ do Chrome > Instalar aplicativo.
